# Свободная музыкальная подборка

Шесть узнаваемых произведений классики в полных записях CC0 / public domain.
Это подборка по узнаваемости: общего рейтинга популярности всех свободных
аудиозаписей не существует. Права проверялись для конкретных исполнений,
а не только для давно опубликованных произведений. Проверено 16 октября 2026 года.

| Произведение | Исполнитель | Длительность | Основание использования записи |
| --- | --- | --- | --- |
| Бетховен — К Элизе | V. Gao (Gaodifan) | 2:56 | [CC0 и собственная передача в public domain](https://commons.wikimedia.org/wiki/File:FurElise.ogg) |
| Бетховен — Лунная соната, I. Adagio sostenuto | Schwarzer Stern | 8:17 | [Собственная запись исполнителя, переданная в public domain во всём мире](https://commons.wikimedia.org/wiki/File:Sonate_Clair_de_lune.ogg) |
| Вивальди — Времена года. Весна, I. Allegro | Free Tim | 3:04 | [CC0, запись из Free Music Archive](https://commons.wikimedia.org/wiki/File:Free_Tim_-_Vivaldos_Spring_from_the_Four_Seasons-Allegro.ogg) |
| Шопен — Ноктюрн ми-бемоль мажор, op. 9 № 2 | Frank Lévy | 4:31 | [Creative Commons Public Domain Dedication, запись Musopen](https://commons.wikimedia.org/wiki/File:Nocturne_in_E_flat_major,_Op._9_no._2.mp3) |

| Бах — Прелюдия до мажор, BWV 846 | Kimiko Ishizaka | 2:42 | [CC0, прямо указанная на странице исполнителя](https://kimikoishizaka.bandcamp.com/track/prelude-no-1-in-c-major-bwv-846) |

Все композиторы умерли в 1925 году или раньше. Для записей сохранены отдельные
основания: CC0, передача записи в общественное достояние автором или прежняя
Creative Commons Public Domain Dedication. Они разрешают распространение
аудио в каталоге приложения и коммерческое использование без покупки лицензии
и обязательной атрибуции. Для записей Musopen просьба указать источник носит
характер благодарности; исполнители и источники всё равно сохранены здесь.

`LicenseRef-Public-Domain` в манифесте обозначает передачу записи в общественное
достояние. Это не переименование её в CC0. В `licenseUri` для таких записей
указана сохранённая редакция страницы с основанием использования. Public Domain
Mark сам по себе не предоставляет права на чужую современную запись.

## Файлы и воспроизводимость

- `manifest.json` — единый источник названий, исполнителей, источников, оснований
  использования и длительностей. `sourceRevisionUri` фиксирует редакцию страницы
  Commons, `sourceSha1` — скачанный исходник, `sha256` — подготовленный MP3.
- `audio/` — полные MP3: 192 кбит/с, 44,1 кГц, stereo, loudness normalization
  `loudnorm=I=-16:TP=-1.5:LRA=11`. Музыка не обрезана; исходные метаданные и
  изображения удалены, добавлены название, композитор и исполнитель.
- Для первых пяти записей `sourceDownloadUri` указывает на исходный файл.
  Для Баха скачана полная общедоступная MP3-версия на странице исполнителя;
  ссылка на страницу сохранена вместо временного подписанного адреса Bandcamp.
  [Копия этой записи в Commons также помечена CC0](https://commons.wikimedia.org/wiki/File:Kimiko_Ishizaka_-_Bach_-_Well-Tempered_Clavier,_Book_1_-_01_Prelude_No._1_in_C_major,_BWV_846.ogg).
- `frontend/public/audio/demo-*.mp3` — идентичные копии для самостоятельной
  сборки frontend. Из `frontend/` команда `npm run audio:generate` обновляет
  копии и `demo-catalog.ts`; `npm run audio:check` проверяет совпадение с манифестом.
  Две старые WAV-заготовки оставлены только в тестовых fixtures для проверки загрузки.

Не требуются обращения к музыкальным сайтам при сборке или воспроизведении.
Каждый подготовленный файл хранится в Git. Хеши проверяются до публикации каталога.

## Обновление уже заполненного серверного каталога

`python -m app.init_catalog` публикует готовые MP3 в S3 и обновляет существующие
шесть слотов, включая записи со статусом `ready`. Идентификаторы слотов прежние:
это сохраняет ссылки из очередей и не добавляет ещё шесть демотреков. Повторный
запуск не создаёт новые треки или новые версии одинакового аудио. Старые объекты
хранилища и пользовательские загрузки эта операция не удаляет.

Обновление выполняется как обслуживание: закройте старые комнаты и остановите
API перед повторной инициализацией, чтобы сохранённые playback snapshots не
ссылались на прежнюю версию музыки. Сам `init_catalog` теперь не требует transcoder:
файлы уже подготовлены. Используйте существующий worker с доступом к БД и S3.

В браузерном деморежиме сохранённая комната получает новые метаданные при чтении.
Если в ней играл заменённый синтетический трек, воспроизведение сбрасывается
на паузу в начале новой записи.
