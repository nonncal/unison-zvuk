# Прогресс фронтенда Unison

Обновлено: 14 октября 2026. Ветка `dev` обновлена до готового Python backend `bbdfa68`, затем фронтенд перенесён на FSD и подключён к реальным HTTP/WS-контрактам. React, TypeScript, Redux Toolkit, React Redux, RTK Query и React Router сохранены.

## Реализация

- Слои app/pages/widgets/features/entities/shared, публичные API, явная связь entities через `@x`.
- Проверка TypeScript AST запрещает импорты вверх, между соседними слайсами и обход публичных API.
- React Router: `/`, `/join/:roomId`, `/room/:roomId`, неизвестный маршрут; lazy/Suspense для экранов.
- RTK Query-подборка комнаты с кешем и пагинацией; сериализуемые room/audio slices в Redux.
- Строгие generated HTTP/WS-схемы Python. Адаптация root playbackRevision, readiness-объекта, nullable-полей трека; целые миллисекунды при отправке.
- Основной режим — FastAPI. Локальная demo-версия включается отдельно и сохраняет прежние сценарии.
- Signed PUT → S3 → Python worker/FFmpeg → общий трек; отмена вызывает DELETE серверного резерва.
- Исправлена передача выросшего аудиобуфера при неизменном ready-state; добавлен регрессионный unit-тест. Таймаут receipt больше серверного ожидания готовности.
- Независимые cookie-сессии, восстановление после refresh, новая вкладка замещает прежнюю, выход передаёт роль.
- Адаптивные desktop/tablet/mobile экраны, native dialogs, keyboard focus, clipboard fallback, reduced motion.

## Проверка

- `architecture:check`, lint, Prettier, TypeScript и production build — проходят.
- 65 общих HTTP/WS fixtures — проходят.
- 13 Vitest-тестов — проходят.
- 12 demo-сценариев Chromium — проходят; viewport 360/390/768/1024/1440 px.
- 5 браузерных сценариев с реальным FastAPI/PostgreSQL/Redis/S3/worker — проходят: независимые сессии, реальное аудио, play/pause/seek, поздний вход, лимит комнаты, refresh, передача роли, замена вкладки, reconnect, upload/FFmpeg.
- Python: 123 модульные проверки прошли; полный запуск без env пропустил 46 интеграционных/системных проверок. Отдельный полный прогон с локальными сервисами: 40/40 PostgreSQL/Redis/S3/WS интеграционных тестов прошли.

При первом полном прогоне обнаружен жёсткий localhost в CORS-тесте backend; исправлен на настроенный APP_ORIGIN. Проверка хранилища с 127.0.0.1 прошла. Полный повторный интеграционный запуск прошёл: 40/40.

Проверка двух независимых browser context подтверждает интеграцию и реальное воспроизведение в Chromium. Она не доказывает NFR 150/300 мс между физическими устройствами. Safari/Android, десятиминутные замеры звука и нагрузочная приёмка остаются отдельными проверками; соответствующие истории не закрыты автоматически.

## Коммиты

Работа разложена по отдельным Conventional Commits: спецификация; FSD shared/contracts; entities/API; features/audio; адаптивные экраны; исправление backend CORS-теста; исправление буфера; lazy-router; браузерные тесты; CI; документация. Старые опубликованные коммиты и история backend не переписаны. Новые коммиты локальные, push не выполнялся.
