# Требования к дизайну Unison

## Направление

Unison похож на песенник: текст песни и названия набраны крупной антиквой, интерфейс вокруг простой и спокойный. Узнаваемый мотив один: две точки слушателей сидят на общей линии перемотки у позиции воспроизведения. Точки не изображают точность синхронизации: при неготовности они показывают ожидание, при отсутствии связи пропадают. Два цвета участников, кобальтовый у ведущего и оранжевый у второго слушателя, остаются единственными насыщенными цветами продукта.

Поверхности отделены ступенью тона, а не линиями. Тени есть только у того, что парит: диалоги, уведомления, поднятая при переносе песня. Без декоративных градиентов, заголовков с одним раскрашенным словом и заглавных подписей без причины. Макет и скриншоты: [docs/screenshots](screenshots/).

## Токены

Светлая палитра задана на `:root`, тёмная переопределяет те же роли при `prefers-color-scheme: dark` и при `data-theme="dark"`. Выбор темы хранится в `localStorage`, `theme-init.js` применяет его до первой отрисовки.

| Роль | Светлая | Тёмная | Назначение |
| --- | --- | --- | --- |
| ground | #EEF0F4 | #0E1016 | фон приложения |
| raise | #E2E5EC | #171A22 | панели, плашки |
| raise-hover | #D5D9E3 | #222632 | наведение, кнопки второго плана |
| float | #FBFBFD | #1D212C | диалоги, уведомления |
| ink | #12151D | #ECEFF5 | основной текст |
| muted | #566074 | #99A2B5 | вторичный текст |
| you (кобальт) | #2547D6 | #6D8BFF | ведущий, главные действия |
| friend (оранжевый) | #D4451A | #FF7448 | второй слушатель |

Дополнительные цвета участников `tone-2…tone-5` для третьего и следующих, семантические ok / bad. Цвет всегда дополняется подписью или иконкой. Текст должен давать контраст AA (4,5:1), крупный 3:1; значимые контуры полей и фокуса 3:1. Контраст светлой темы подбирался вручную и измерителем не проверялся.

Типографика: заголовки, названия песен и текст песни в Cormorant Garamond (600-700, крупно, трекинг −0,01…−0,03 em); интерфейс в Golos Text. Оба шрифта переменные, кириллица и латиница поставляются локально через `@fontsource-variable`. Шкала: 14 и 16 px для интерфейса, 26-28 px заголовки панелей и диалогов, 34-56 px название песни, 46-92 px заголовок главной. Время с tabular numerals. Строки текста до 75 знаков.

Шаг интервалов 4 px. Максимальная ширина контента 1320 px, поля 32 px на десктопе и 16 px на телефоне. Радиусы: поля 12, плашки 14-20, диалог 20, кнопки круглые. Фокус 2 px с отступом.

## Экраны и состав

1. **Главная:** название Unison, фраза «Одна песня. Один момент.», короткое пояснение, «Создать комнату», поле имени при старте, маленькая предметная демонстрация общей дорожки. Создание и вход понятны без маркетинговых обещаний. Вход по приглашению обычно прямой, ручной ввод всей ссылки можно оставить вспомогательным действием.
2. **Предпросмотр/вход:** имя комнаты, два места с честным состоянием занятости, своё имя, «Войти и включить звук», короткий текст о локальном разрешении звука. Отдельные состояния invalid/full/expired/closed. Не запрашивать микрофон/камеру.
3. **Пустая комната ведущего:** header с названием и кнопкой приглашения; два места участников; пустой плеер «Выберите первую композицию»; действия «Открыть подборку» и «Загрузить файл».
4. **Комната:** крупная обложка/честный placeholder, title/artist, синхронизационная дорожка, времени elapsed/duration, общий play/pause/seek, локальный volume/mute; участники рядом, статус «Слушаете вместе» только при готовности. Библиотека — боковой drawer, а не постоянный тяжёлый dashboard.
5. **Слушатель:** общие controls read-only, «Воспроизведением управляет Кирилл», локальный звук активен; не скрывать состояние трека и возможность выйти.
6. **Подборка:** поиск, список треков с названием/автором/длительностью и явным «Выбрать» для ведущего; поиск без результатов «Ничего не найдено. Попробуйте другое название». P1 отдельное «Добавить в очередь», не путать с немедленным переключением.
7. **Загрузка:** выбор/drag-drop, формат/размер/срок хранения, отправка с percentage и отменой; processing без выдуманного процента; ready; каждая ошибка с действием исправления. Заголовок файла сокращать, не двигать layout.
8. **Приглашение:** копируемая ссылка, «Копировать ссылку» → toast «Ссылка скопирована»; при отказе clipboard — доступное поле с ручным копированием.
9. **Системные состояния:** «Включить звук», «Загружаем композицию», «Восстанавливаем соединение», «Теперь вы ведущий», ожидание второго, готовность не всех с явным выбором ведущего, новая вкладка, завершение комнаты, подтверждение закрытия.
10. **P1/P2 макеты отдельно:** реакции, общая очередь, до 10 аватаров/list, управление очередью/ролями. В MVP нет неработающих controls расширений.

## Компоновка и адаптивность

```text
Desktop1440
┌ Unison  Название комнаты                Пригласить  Выйти ┐
│                                                         │
│   обложка + композиция        Кирилл / ведущий            │
│   общий timeline             Аня / слушает               │
│   общий плеер + local volume                            │
│   Подборка / Загрузить                                   │
└─────────────────────────────────────────────────────────┘

Mobile390
┌ Unison              Пригласить / меню ┐
│ Кирилл        Аня                     │
│ обложка / название                    │
│ timeline и статус                     │
│ общий play/pause                      │
│ локальная громкость                   │
│ Подборка / Загрузить                   │
└───────────────────────────────────────┘
```

Desktop≥1024: плеер занимает примерно 2/3, участники 1/3; library drawer шириной 420–480. Tablet 768–1023: участники над плеером, side drawer поверх контента. Mobile 360–767: одна колонка, без горизонтального scroll; библиотека и upload как полноэкранный sheet/dialog, controls не перекрывают содержимое и safe area. Проверить 320 px как стресс-тест текста, основная поддержка от 360. Целевые hit areas≥44×44, между соседними опасными действиями≥8 px. Landscape и 200% zoom не ломают ключевые действия.

## Компоненты и интеракции

Button primary/secondary/quiet/danger с default/hover/focus/pressed/disabled/loading; IconButton с доступным именем; TextField default/focus/error/disabled; Dialog/Sheet с trap focus, Esc и возвратом focus; Toast success/error; ParticipantTile host/listener/ready/loading/offline; AudioPlayer host/listener; Timeline idle/syncing/synced/paused; SeekSlider и VolumeSlider; TrackRow selected/ready/disabled; UploadPanel состояния; ConnectionBanner; EmptyState; ReactionButton P1; QueueItem P1.

Не смешивать общую паузу с локальным mute: разные символы и подписи. Tooltip помогает, но не заменяет доступное имя. Status announcements через aria-live polite, критические ошибки assertive дозированно. Прогресс не озвучивать каждую секунду. Не использовать waveform как seek control без корректного slider; waveform возможна только по реальному файлу, иначе честная абстрактная дорожка.

Motion 140–220 мс для действия/перехода drawer/feedback, одна краткая сцена сближения курсоров при подтверждённом совместном старте. Нет бесконечных пульсаций, эквалайзера «для красоты» и появления каждой карточки fade-up. Reduced motion — немедленные переходы, статичная линия, без параллакса. В состоянии paused движение останавливается.

## Тексты

Использовать sentence case и глаголы: «Создать комнату», «Пригласить друга», «Войти и включить звук», «Выбрать композицию», «Загрузить файл», «Воспроизвести для всех», «Пауза для всех», «Выключить звук у меня», «Выйти», «Закрыть комнату для всех». Ошибки конкретны: «Файл больше 50 МБ. Выберите файл меньшего размера»; «Не удалось обработать аудио. Выберите MP3, WAV или M4A»; «Комната уже заполнена»; «Связь восстановлена. Возвращаемся к композиции». Пример UI округляет 50 MiB до «50 МБ», точный предел объясняется в help.

Демонстрационный контент: комната «Вечер на двоих», ведущий Кирилл, слушатель Аня. В подборке девять свободных записей, три из них с текстом (см. [backend/README.md](../backend/README.md#каталог-музыки)).

## Реализация и приёмка в браузере

Дизайн реализуется непосредственно в React/CSS. Основные ширины проверки: 1440, 1024, 768, 390 и 360 px. На десктопе плеер расположен слева, участники справа; на планшете сохраняются две колонки с обложкой над названием. На телефоне общие кнопки и прогресс закреплены снизу; вкладки «Очередь» и «Участники» переключают вторичное содержимое.

Ряд управления: перемешивание, предыдущая песня, play/pause, следующая песня, повтор. Локальная громкость вынесена отдельно. Статус готовности участников подписан словами. У слайдера есть клавиатурное управление и доступное текстовое значение времени. Обложка из файла имеет приоритет над заглушкой, ручная замена — над встроенной.

Проверять переполнение, длинные названия, фокус после диалогов, состояния подключения/ошибки/заблокированного звука и reduced motion. Подтверждённая готовность буфера не называется измеренной акустической синхронностью.

Текст песни стоит под плеером: текущая строка крупная и яркая, остальные тише, список сам прокручивается и замирает на четыре секунды, если пользователь крутит его сам. Очередь переносится перетаскиванием. Уведомления появляются справа внизу и не закрывают управление плеером.
