# Караоке-текст как в Apple Music — оценка (не реализовано)

**Можно ли для своей загруженной музыки: да, но не автоматически.**
- Тексты в тегах (ID3 USLT, M4A `©lyr`) обычно без времени; синхронные SYLT/LRC встречаются редко. ffprobe уже отдаёт теги — можно читать как есть.
- Практичный путь: загрузка `.lrc` рядом с треком (строки с `[mm:ss.xx]`), хранение в БД как JSON `[{t_ms, text}]`, рассылка через `track.updated`; клиент подсвечивает строку по уже существующей общей позиции (`timelineAt`) — синхронность со всеми бесплатна.
- Автосинхронизация обычного текста — отдельная задача (forced alignment, например whisper/aeneas): тяжело, на CPU медленно и неточно для пения.
- Права: текст песни — объект авторского права; для демо — только свои/CC0 тексты, не подтягивать из интернета.
- Оценка: LRC-загрузка + экран текста ≈ 1–1.5 дня (backend 0.5, UI 1); автосинхронизация — 3+ дня, риск высокий. Для 17–18 октября рекомендую только LRC и только после стабилизации.
